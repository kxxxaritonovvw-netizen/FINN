# FINN

Личный месячный бюджет: поступления дохода, плановые расходы и регулярные платежи с датами.

Первый интерфейс — мобильный веб в тёмной теме, на всю ширину устройства. Далее — личный кабинет, вход через Google и возможный нативный iOS-клиент.

[Проект архитектуры](docs/architecture.md) — стек, модель данных, авторизация, API и этапы реализации.

Первый экран реализован в `apps/web`: месяц, переключатель дат (по умолчанию 5 и 20) с настройками, отдельные списки расходов для каждой даты. У строки редактируются название, сумма и валюта; чекбокс отмечает расход закрытым. Можно добавлять строки и удалять их через контекстное меню по удержанию или правому клику. Пока значения хранятся только до перезагрузки страницы; сервер и авторизация ещё не подключены. Выбор валюты меняет обозначение, без конвертации суммы.

Запуск: `pnpm install`, затем `pnpm dev`. Приложение открывается на `http://127.0.0.1:3000`.

Проверки: `pnpm typecheck` и `pnpm build`.
